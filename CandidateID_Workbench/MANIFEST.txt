1. ROOT EXECUTABLES & STANDALONE RUNTIME BINARIES
================================================================================

1. Launch.exe:
   - Role: Native Win32 double-clickable launcher wrapper (37 KB).
   - Provenance: Custom Win32 C++ application (zero Qt dependencies).
   - Behavior: Automatically resolves relative path to workbench_app.exe, preserves
     working directory for bundled assets, forwards CLI parameters, and displays
     informative graphical error dialogs if components are missing.

2. workbench_app.exe:
   - Role: Main engineering workstation desktop application (384 KB).
   - Views: Geometry & Point Cloud, 1D Thermal FEA, Multicore Performance Benchmark,
     Embedded Hardware Mocks, and Neural Network Backpropagation.

3. workbench_experiments.exe:
   - Role: Native C++ headless experiment and verification runner (173 KB).
   - Capability: Generates and validates all numerical CSVs independently of Qt GUI.

4. workbench_gui_tests.exe:
   - Role: Automated QtTest GUI integration test harness (410 KB).
   - Coverage: 9 GUI scenario test methods + setup/cleanup (11 passed QtTest entries total, 1810 ms) verifying all 5 views and modal workflows.

================================================================================
9. DISCLAIMERS & PROVENANCE DECLARATIONS
================================================================================

1. Embedded Hardware Adapters:
   All hardware interfaces (ESP32-DevKitC MCU, Arty A7-35T FPGA, JTAG-HS2 TAP Bridge)
   are strictly SIMULATED software mocks. No physical hardware is connected,
   powered, debugged, or programmed. JTAG is an interface adapter, not a compute board.

2. Thermal Temperature Point Cloud:
   The supplied temperature CSV dataset (synthetic_temperature_nodes.csv) is a
   SYNTHETIC test fixture generated for UI visualization. It is NOT an actual
   ANSYS simulation export.

3. File Format Scope:
   Only ASCII STL is supported in the geometry viewer. Binary STL and proprietary
   CAD solid models are intentionally rejected by design with actionable diagnostics.
